# Grounded Ambition: source and adaptation

Source: Felix Rieseberg, *How to be more ambitious: A tutorial for humans with models*, 13 October 2026.
https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/

The source proposes four directions: Speed (same work in less time), Altitude (the outcome beyond an individual task), Depth (professional methods and underlying data), and Range (useful methods from multiple fields). It recommends real instruments rather than expert vocabulary, original data for assumption tests, unseen data for predictive checks, an outside judge, and actual interdisciplinary techniques rather than persona role play.

## Asympta adaptations

These are our operating safeguards, not empirical results attributed to the source. Use the methods selectively at meaningful planning boundaries; do not make routine work bigger. Preserve the explicit deliverable and creative intent. Difficult stretch targets remain hypotheses, not promised feasibility. Do not dismiss investigation merely because a problem is longstanding or open. Work within authorization and finite resource limits, retaining failed experiments and checkpoints.

Prefer the smallest relevant authorized source material sufficient to reject a wrong assumption. A second model's agreement is not independent acceptance. Separate tool acknowledgment, source identity, test results, actual device/provider behavior and appropriate human review. Predictions need held-out evaluation, leakage prevention and false-positive reporting.

The skill does not execute tools, grant permissions, start agents, install software or create monitoring. It reuses existing Work and grounding tools only where appropriate. Tests of skill packaging/routing do not establish better autonomous behavior, creativity or end-to-end performance; those benefits require comparable real-task evaluation.
